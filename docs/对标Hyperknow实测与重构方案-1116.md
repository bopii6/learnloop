# 对标 Hyperknow 实测与重构方案（2026-11-16）

实测方式：同一题目「我想学会用 SQL 做数据分析」，在 Hyperknow（Venus 1 Pro）与我们本地各走一遍「提问 → 建课」；白板分别用 Hyperknow 已有课「语言即概率」和我们新生成的 SQL 课第 1 讲。视口 1280×800。

## 一、提问 → 课程

| | Hyperknow | 我们 |
|---|---|---|
| 首屏 | 输入卡位置稳定 | 「上次还有一门课」横幅加载后插入，把输入框顶下去（点击/输入落空） |
| 过程呈现 | 一列"代理执行日志"：正在理解需求 → 网络检索（实时来源列表，完成后折叠成一行 ✓）→ 阅读资料 → 搭建单元 → 逐单元展开，每步打勾 | 分块大卡片，步骤感有，但不会自动滚到最新处 |
| 澄清 | 2 题，一行问句 + 小胶囊选项 + 同一行「其他…」输入；底部固定条「答完就开始生成 / 跳过，用默认答案 / 取消」 | 4 题，每题大卡片 + 长选项说明；单选也要再点「继续」；问题质量**比它好**（紧扣资料） |
| 蓝图 | 不打断：右侧滑出面板实时"长出"思维导图（节点计数、深度图例），生成继续进行 | 中途要求确认蓝图；导图节点互相重叠、字小 |
| 速度 | 慢（8 分钟以上），但一直有可见进展 + token 计数 | 快（约 2 分钟）——**我们的优势** |
| 细节 | 「遇到问题？」入口真实存在 | 小贴士说"点右上角助手"，但没有助手；课时数字前后不一致（8h / 5.8h / 5h45m；16 课节 / 0/14 讲） |

## 二、白板课堂（核心）

**最大的差别不在界面，在"教学引擎"。** 两边前端结构几乎相同（手写字体卡片叠在 Excalidraw 画布上，卡宽 380–444、缩放 0.7、3 列），差在讲法：

| | Hyperknow | 我们 |
|---|---|---|
| 讲稿 | **实时生成、随学员回答改变走向**：学员答"永远选最高的"→ 老师"不完全对" → 下一块板书直接讲贪心 vs 采样 | 一次性生成整节讲稿，从头播到尾 |
| 互动频率 | 开讲约 1 分钟就第一次提问，之后约每 1 分钟一次；预测型问题（"你直觉觉得下一个词是什么？"），选项胶囊 + 可自由输入 | 整节课末尾 1 道题 |
| 每拍长度 | 一句话（≤40 字）配一个板书动作 | 字幕一段 100+ 字 |
| 字幕 | 底部居中一行纯文字，逐字浮现 | 黑底大字幕条，压住板书 |
| 板书 | 小卡片（标题 + 2–6 行），写具体例子和数字（mat 60% / floor 20%…）、公式 + 红圈标注、配图；镜头跟随新卡平移 | 只有关键词碎片；窄窗口下一行五六个字就折行；写满后被顶出屏幕 |
| 右侧面板 | 讲话全文 + 动作标签（板书/配图/圈画）+ 学员回答气泡；底部输入框随时答题/提问，带麦克风、暂停、停止 | 把板书原文再抄一遍 |
| 外围 | 首次进入 7 步导览；交流方式选择（文字 / 语音+文字，语音可直接开口打断）；静音；音色/语速/字体设置；回放分享、导出 PDF/Markdown | 有课前设置、暂停/语速/重听/没听懂；无导览、无导出 |
| 课程页 | 每个知识点「学习 / 练习」两个入口 + 掌握度圆环（未开始→已尝试→熟悉→熟练→已掌握） | 课节列表 + 访问过即打勾 |

## 三、我们能做得比它好的地方（升级而非照抄）

1. **快**：建课 2 分钟 vs 8 分钟以上。保住。
2. **编程课能真动手**：浏览器内跑 Python 并判题（分步课样板已验证）。Hyperknow 白板里没有可运行代码。把它做成白板里的一种"检查点卡片"。
3. **学员控节奏**：Hyperknow 也是系统定速。我们加「空格 = 暂停/继续」「→ = 下一句」，听懂了可以快进。

## 四、重构方案

### 白板（先做）
1. **教学引擎改为"分段 + 自适应"**：一节课 = 若干段（每段 1–2 分钟），每段以一个检查问题结束；学员作答后，带着他的原话去生成下一段（先给一句即时反馈，后续板书按他的理解走）。不再整节预生成。
2. **讲法规则**：一拍一句话（≤40 字）；板书写具体例子/数字/公式，不写关键词碎片；开讲 1 分钟内第一次提问。
3. **版面**：白板占满宽度，右侧面板改为可收起的浮层；版面参数按真实宽度 + 缩放计算；镜头跟随新卡片。
4. **字幕**：一行纯文字，去掉黑底条。
5. **右侧面板**：只放讲话全文 + 学员回答，底部输入框随时答题/提问，暂停 / 停止。
6. **编程检查点**：编程类课程的检查问题可以是"写一行代码"，浏览器里运行判题。

### 提问 → 课程（后做）
1. 首屏横幅不再顶动输入框。
2. 澄清改轻：一行问句 + 胶囊选项 + 行内「其他」；单选点了就走；底部固定「跳过，用默认答案」；新内容出现自动滚到视野内。
3. 去掉蓝图确认关卡：蓝图在右侧面板实时生长，生成不中断；修好节点重叠。
4. 修文案与数字一致性（假小贴士、课时、课节数）。
