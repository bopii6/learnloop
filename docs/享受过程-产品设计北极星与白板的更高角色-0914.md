# 享受过程：产品北极星与白板的更高角色

日期：2026-09-14 · 起点用户原话：希望大家在学习新知识、完成新目标的过程中，**非常享受这个过程**。这是最终目标。

## 0. 先说结论

你这句目标，翻译成产品语言是一句话：

> 学员上课时的状态，不该是"我在看一门好课"，该是"**我在打我自己的仗，而且正在打赢**"。

判断每个功能的高矮，只用一把尺子：

> **这 30 秒，学员是在"看"，还是在"做"？他做完，能看见世界有什么变化？**

"看"的上限是电视——再好看的课也是别人在表演。"做"的上限是游戏——自己的目标在推进，自己每一步都有回应。享受藏在"做"里。

## 1. 享受是设计出来的，不是内容好就自动有

关于"人什么时候享受"，心理学有几个很硬的结论。每个结论后面，对一件咱们已有的东西。

**一、挑战比能力高一点点，马上知道结果——这就是乐趣（心流理论）。**
太简单无聊，太难崩溃，高一点点最爽，而且必须"立刻知道对没对"。
→ 对到咱们：学员两极分化（要强引导的 / 要密度的），一直想用"难度开关"解决。心流理论说：这不是三档开关的问题，是**匹配**问题。挑战要贴着每个人的能力走，动态调。「没跟上」按钮就是现成的降档信号，练习答对就是升档信号——匹配的原料已经在手里了。

**二、人只享受"自己有分量的行动"（自主 + 胜任）。**
0912 实测过：整节课用户唯一爽的瞬间是弹题。为什么？因为那是**全课唯一一个冲着他来、等他回应**的时刻。
→ 对到咱们：这个实测结果比任何理论都值钱。它说明现在的课堂 95% 的时间里，学员是个旁观者。

**三、爽的不是终点，是"离终点近了"的每一步（进展原则）。**
爬山、装修、打游戏，享受都来自看得见的推进。
→ 对到咱们：结课作品就是那个终点（已经定了）。但学员在听课过程中，**看不见作品在长**。他不知道这节课给他的作品添了哪块砖。进展明明存在，没被显示出来。

**四、人记住的是最高点和大结局，不是平均值（峰终定律）。**
一场 2 小时的课，学员离开时只带走两样东西：最带劲的一刻，和结尾的感觉。平均质量再高，没有峰 = 白讲。
→ 对到咱们：现在每节课的节奏是均匀的——六个一样的小节，没有设计过的最高点，结尾是"小结检验"。

## 2. 更高维的诊断：现在整个产品是一场"单播"

把产品摊开看：搜索、澄清、蓝图、大纲、导演、讲稿、板书、测验、作品工坊——每个零件都在为**内容质量**服务。这套机器把"印出一门好课"做到了八十分。

但"过程体验"这件事，目前是零散的：弹题是被排进去的，徽章是答完才有的，"没跟上"是学员求救用的。没有任何一个环节的出发点是"**让学员动起来、让他看见自己的进展**"。

一句话诊断：**我们把"印好课"当成了产品，把"打得爽"当成了装饰。下一个数量级在后者。**

这不是推翻"课程印刷厂"的定位——印刷厂解决的是"课从哪来、便宜、成体系"。享受过程解决的是"课算什么"：课不是货物，是学员朝自己目标走的那段路本身。

## 3. 白板的更高角色：从显示屏到战况图

白板到现在换过三个角色：

1. **打印机**（0912 诊断之前的现状）：把讲义写到白板上，字多、没人看。
2. **舞台**（0913 动效规范之后）：讲师在上面表演，有节奏、有强调、有小人。白板是老师的地方。
3. **战况图（下一步）**：白板是**学员的征途地图**——

具体长这样：开课第一画，画的就是**学员的结课作品骨架**（这个作品由哪几块组成，比如一份销售报表 = 数据 + 计算 + 图表 + 结论）。之后每节课，讲师讲到哪块，就在骨架上**点亮那块、添上那块砖**。课与课之间，骨架不擦——它是长跑计分牌。结课那天，长卷上留下的就是：作品图纸 + 一路啃下来的痕迹。

这样白板上的每一笔对学员都有了新含义：那不再是"老师写的提纲"，那是"**我的目标被啃掉了多少**"。

注意：这不是换版式。白板长卷形态不动（已定稿的红线）。换的是长卷的**意义**——而且它和 0913 那个知识地图提案（以结课作品为根的依赖图）天然是同一件事：那个提案当时是"诚实摊开还要学什么"，现在有了体验层的理由——**它是享受的进度条**。

## 4. 让课堂从"看比赛"变"打球"（最大的一根杠杆）

具体形态：**每 2-3 分钟一个学员回合**。不一定是做题，可以是：

- **预测**："这版两行代码，能上线吗？"——学员先猜，讲师再揭晓（猜错是故意设计的，猜错之后听懂的才叫爽。这叫先试后教，有扎实的实验证据：先挣扎后讲解，比直接讲解记得牢）。
- **二选一**："这里 value 该填 1 还是 UUID？"——学员选，讲师顺着他的选择讲。
- **判断**："这个锁现在安全吗？"——白板上就有线索，学员点白板作答（白板可点已经做好了）。

关键是三个字：**有后果**。学员的回答要影响接下来发生的事——至少影响讲师走哪个例子、用哪个讲法；答对了当场确认，答错了当场翻案。零件全是现成的：checkpoint 机制、徽章、白板可点、「没跟上」。缺的不是功能，是**频次（每 2-3 分钟一次）、位置（讲机制之前先让学员碰）、后果（答案改变下一步）**。

## 5. 峰终工程：导演要对"体验"负责，不只对"讲对"负责

0914 那份编排调研（记住讲过什么、按型排戏、具体钩子）解决的是"听不进去"。同一个导演，再加一条体验责任：

- **每课保底一个峰**：先猜 → 事故 → 揭晓。揭晓那一刻就是学员带走的高点。
- **每课一个好结尾**：不是"小结检验"，是**能力宣告 + 盖章**——"现在你可以独立写出原子加锁了"，白板金句盖章，徽章落袋。结尾的感觉是"我做到了"，不是"课讲完了"。

## 6. 先装尺子，再踩油门

享受必须能测量，否则每轮改造又要靠体感吵架。

- **北极星建议：主动下一讲率**——下课 24 小时内，学员**自己**点开下一讲的比例。这个数字高，说明过程真的爽；内容再好但不想再来，就是零。
- 分项：完播率、重听率、「没跟上」率（已有埋点）、主动提问率、练习正确率、回放分享率。
- 每个新功能上线前，先过第 0 节那把尺子。

## 7. 推荐路线（按杠杆大小排序，你拍板）

1. **装尺子**（约 1 天）：北极星埋点上线。便宜，且后面每一步都需要它说话。
2. **回合制课堂**（3-5 天）：checkpoint 前置、加密、加后果。把 95% 的旁观时间往"做"里挪——最大的一根杠杆。
3. **峰终工程**（2-3 天，和 0914 编排三招合并实施）：导演每课造一个揭晓时刻 + 一个能力宣告结尾。
4. **作品骨架点亮**（3-5 天，与知识地图提案合流）：白板从"本讲提纲"升级为"征途计分牌"。
5. **白板可问可拖**（2 天）：在已完成的白板可点之上，点任何板书发问、拖选作答。锦上添花，排最后。

大版本 2.0 的答辩日、作品集、AI 同学班级，是这件事的社交层（跟真人和同伴一起享受）——方向完全一致，顺序也不冲突。

## 8. 红线：为了享受，这几件事不做

- **不做塑料游戏化**：积分、徽章如果和真实能力无关，会反过来杀死享受（外部奖励侵蚀内在动机，这是心理学定论）。徽章只发"能力事实"：你现在真的会做这件事。
- **自主不等于无限选择**：零基础学员要的是被带着走。给选项永远不超过 3 个，且都可以闭眼选。
- **不动白板长卷形态**（已定稿）。
- **不为有趣丢忠实**（0914 已定）：钩子必须来自教材内容，事实可回溯页码。
