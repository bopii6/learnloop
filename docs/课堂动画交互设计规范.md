> 版本：v1.0（2026-09-11）

> 目标读者：课堂播放器开发、课程生成管线「导演」提示词设计

## 0. 一句话总纲

**动画是导演手段，不是装饰。每一次运动都必须回答：观众此刻该看哪里？（吸引人）这个运动帮懂了吗？（专业）它是否抢了讲解的注意力？（舒服）**

三条验收标准的专业定义：

| 标准 | 含义 | 反例 |
|------|------|------|
| 专业 | 运动有依据：时长、缓动、运镜遵循成体系的规范，不随意 | 元素乱飞、缓动忽快忽慢、镜头无目的地乱晃 |
| 吸引人 | 注意力被精确引导：讲到哪，视觉焦点就在哪，无竞争焦点 | 板书全部糊在一屏、重点不突出、画面静止枯燥 |
| 舒服 | 不增加认知负荷与生理负担：观众始终有余力听讲解 | 动画太密没时间读、镜头频繁大幅运动让人晕 |

## 1. 认知科学基础（为什么这么设计）

### 1.1 Mayer 多媒体学习原则（实证基础，直接约束动画设计）

| 原则 | 对课堂动画的约束 |
|------|-----------------|
| **一致性原则** Coherence | 装饰性动画一律不做。画面上任何运动都会被视觉系统强制追踪，运动越多、离题越远，学习越差。**能不动的元素坚决不动**。 |
| **标记原则** Signaling | 动画的核心价值就是标记：圈重点、点亮、变色都是在告诉观众"看这里"。每句话的动画必须指向**当前正在讲的那一个**知识点。 |
| **空间接近原则** Spatial Contiguity | 文字和对应的图形必须就近出现（箭头从结论指向图形、标注贴着曲线写），不许让观众在画面两端来回对照。 |
| **时间接近原则** Temporal Contiguity | 讲到"这条曲线起飞"的同时曲线动画起飞——**动画与 TTS 语音同步出现**，不许提前也不许滞后超过一拍。 |
| **分段原则** Segmenting | 一句话一个节拍、一次只推进一个画面事件（我们的 planItemLines 一句一动作正是这个原则的实现）。观众处理完一段再进下一段。 |
| **冗余原则** Redundancy | 字幕（逐字稿）+ 语音 + 画面三通道已满负荷，**不要再用大段文字动画重复语音内容**。板书写关键词，不抄句子。 |

### 1.2 认知负荷的三个来源 → 三个设计开关

- **外在负荷**（画面混乱造成的）：靠一致性原则压——控制同屏元素数量。
- **必要负荷**（内容本身的难度）：靠分段与预训练缓解——每节开头给"地图"（先看整节课的结构，即以终为始）。
- **生成负荷**（理解所需的思考）：靠节拍留白保护——**每拍之间留 300~500ms 静止**，让观众完成"看懂"这个动作。

### 1.3 同屏密度红线

- 讲解中同屏（当前镜头视野内）**信息组块 ≤ 4±1 个**（如：一个标题 + 一张卡片 + 一个圈重点 + 角色它正好）。
- 超出时必须用**运镜**解决：推近当前块、拉远看结构，而不是缩小字塞进去。

## 2. 动画运动学规范（怎么动才专业）

### 2.1 时长标准（综合 Material Design 3 / Nielsen Norman Group）

| 运动类型 | 时长 | 说明 |
|----------|------|------|
| 微反馈（脉冲、点亮闪烁） | 150–300ms | 强调已存在元素 |
| 元素入场（弹出、淡入+位移） | 250–400ms | 配 easeOutCubic |
| 元素退场 | 150–250ms | 配 easeIn（快速离场不纠缠） |
| 手绘线条落笔 | 400–800ms | 跟笔画长度走，粗线可到 1s |
| 数据生长（柱状、曲线绘制） | 600–1000ms | 数值感需要过程时间 |
| 路径运动（小球滚曲线） | 1200–2000ms | 必须用 easeInOut，起停有呼吸 |
| 运镜·小幅推拉（同区块内） | 400–900ms | 视野连续 |
| 运镜·转场（跳到新区块） | 1200–1600ms | 目标先于语音关键词到达 |
| 结课长镜头巡游 | 8–10s | 一次，只一次 |

**动画时长铁律：动画期间观众不需要"读"，只有"看"。凡是伴随新文字出现的动画，动画结束时刻 ≤ 文字被读完的时刻；读不完就加节拍时长，不给动画提速。**

### 2.2 缓动标准（缓动曲线族）

| 场景 | 缓动 | 理由 |
|------|------|------|
| 元素入场 | easeOutCubic | 快进慢停，像落在纸上 |
| 元素退场 | easeInCubic | 迅速让位 |
| 运镜（一切镜头移动） | easeInOutCubic | 电影感，起停无顿挫 |
| 长镜头巡游 | easeInOutSine | 更柔，长时间不晕 |
| 路径运动（滚、飞） | easeInOutCubic | 有加速有减速才像"物理世界" |
| 庆祝类 | easeOutBack（轻过冲） | 情绪释放，唯一允许过冲的地方 |

**禁用弹跳（bounce）类缓动于知识性动画**——IBM 与 NN/g 均指出装饰性曲线分散注意力；只在庆祝/彩蛋时刻用。

### 2.3 迪士尼十二原则的课堂精选（其余七条对知识动画是毒药）

1. **挤压与拉伸**（Squash & Stretch）→ 只给角色（角色蹦跳），板书元素永不形变。
2. **预备动作**（Anticipation）→ 角色跳走前先下蹲一帧；重要的圈重点先轻微脉冲一次再落笔。
3. **舞台调度**（Staging）→ 每拍只有一个主角元素；次要元素退到 60% 透明度而不是删掉（回看时仍在）。
4. **跟随与重叠**（Follow-through）→ 小球滚到终点后轻微脉冲一次再停；箭头落笔后笔头轻颤一瞬。
5. **缓入缓出**（Slow In/Out）→ 一切运动（见 2.2）。
6. **弧线运动**（Arcs）→ 角色跳跃走弧线不走直线；路径运动沿内容本身的形状（曲线/流程）。
7. **次动作**（Secondary Action）→ 角色的动作叠加在板书节拍上（板书落笔时角色蹦一下），但次动作时长 ≤ 主动作一半。

**明确不用**：夸张（Exaggeration，知识内容不夸张）、错觉立体（Solid Drawing，保持手账平面风）、慢动作（Slow Motion，拖节奏）。

## 3. 运镜语言规范（本研究的核心增量）

白板长卷的**版式不变**（已定稿：白板长卷是唯一形态），运镜是叠在长卷上的一层"虚拟摄像机"，通过改变视野而非改变内容来引导注意力。五种标准镜头：

| 镜头 | 何时用 | 参数 | 情绪价值 |
|------|--------|------|----------|
| **开场全景** Opening | 每节课 0 号拍：整卷缩略一瞥 | zoom≈0.5，1.5–2.5s，easeInOutCubic | 以终为始：先给地图再上路，降低迷路焦虑 |
| **跟随落笔** Follow | 默认机位：镜头跟随当前落笔点 | zoom 1.0–1.3，保持落笔点在视野下 1/3 | 阅读稳定，如有人陪你逐行读 |
| **推近细节** Detail | 讲一个图/公式/关键词的内部结构 | zoom 1.3–1.5，0.5–0.9s | "凑近看"，天然的通知机制 |
| **转场跳切** Transition | 章节切换（一站→下一站） | 长距离平移 1.2–1.6s，easeInOutCubic | 用镜头运动代替画面切换，保持空间连续感（长卷的全部意义） |
| **结课巡游** Recap | 最后一拍：拉远后自底向上整卷巡游 | zoom≈0.55，8–10s，easeInOutSine | 复述结构 + 成就感（"我们走了这么远"） |

**运镜规则**：
1. 每分钟运镜 ≤ 6 次；相邻两次运镜之间至少隔一个完整节拍。
2. 运镜目标必须与语音转场词同步（"第一站""接下来""最后一站"是运镜的天然触发词）。
3. 转场时**先动镜头、后落板书**：镜头出发 → 落定 → 新板书弹出，三个动作不许同时。
4. 结课巡游期间不再有任何新板书，字幕只做总结句。
5. 检测到用户 `prefers-reduced-motion` 或设置关闭运镜 → 退化为线性跟滚（v1 demo 顶栏的开关即此对照模式）。

## 4. 形状表演形式库（已验证可实现的 9 种）

按「引导注意力 → 展示过程 → 情绪收尾」排序，每种给出标准参数。生成管线按讲稿语义自动选型（后续「导演」提示词的选型表）：

| # | 形式 | 触发语义 | 参数 | 来源验证 |
|---|------|----------|------|----------|
| 1 | 板书弹出 | 出现一个新概念/卡片 | 淡入+上移10px回落，300ms easeOutCubic | 两版 demo |
| 2 | 落笔描线 | 出现一条推导线/连线/下划线 | stroke-dashoffset 生长，500–800ms easeOutCubic | v1 demo |
| 3 | 圈重点 | 一句话里出现关键结论 | 手绘红圈落笔 650ms + 关键词脉冲 900ms | 两版 demo |
| 4 | 节点点亮 | 流程/步骤讲到第 N 步 | 该节点弹出 500ms，其余保持暗 | 两版 demo |
| 5 | 数据生长 | 对比、数量、排序语义 | 柱高从基线生长 700–900ms easeOutCubic | 两版 demo |
| 6 | 路径运动 | 趋势、过程、因果链 | 小球沿曲线 1.6–1.9s easeInOutCubic，终点脉冲一次 | 两版 demo |
| 7 | 闭环旋转 | 循环、迭代、闭环语义 | 箭头环 360° 自旋 2.2s easeInOutCubic，节点不转 | v1 demo |
| 8 | 面积填充 | 量变、积累、复利语义 | 曲线下方柔和填充 900ms | v1 demo |
| 9 | 撒花庆祝 | 结课、完成、里程碑 | 彩纸 1.9s 抛物线 + 角色跳 800ms easeOutBack | 两版 demo |

**选型三问**（写进导演提示词）：
1. 这句话的动词是什么？（"讲不清"→圈重点；"越来越快"→路径运动；"四步"→节点点亮）
2. 这句话之后观众应该记住什么？动画是否让那个东西更醒目了？
3. 同一个形式连续用了几次？连用 ≥3 次必须换形式或休息一拍（防止可预测性导致的注意衰退）。

## 5. 角色规范（白板原住民角色）

- **定位**：白板原住民、学习者的人格化身，不是讲解者（讲解是语音+板书的事）。
- **出场**：每节 hop 一次落位（650ms 跳跃 + 挤压拉伸），节间安静陪读；**每次转场跟着换位**，转场是它唯一的高频动作。
- **情绪映射**：默认微笑陪读；知识点亮时蹦一下（次动作）；圈重点时歪头；结课撒花时跳 90px。
- **禁忌**：不遮挡板书落笔区（永远站在当前视野右侧安全区 x≥850/1000）；不做需要理解的复杂表演；说话（气泡）时不与字幕同屏。

---

## 6. 舒适红线（不可逾越）

1. **阅读保障**：每拍最短时长 = 字幕字数 × 180ms + 800ms（42 字上限对应 ~8.4s），节拍时长取该值与语音时长较大者。
2. **运动密度**：同时进行的动画 ≤ 2 个（1 主 + 1 次）。
3. **晕动防护**：单次运镜视野位移 ≤ 1.5 屏高；zoom 变化幅度 ≤ 2×；巡游速度 ≤ 250 板书单位/秒。`prefers-reduced-motion` 时全部镜头改为硬切。
4. **对比与无障碍**：动画元素不依赖纯色区分（色弱友好）；所有关键结论同时有文字形态存在，动画只是强调。
5. **可中断**：任何时刻暂停/回看，暂停时画面冻结在当前完整板书状态（不受动画半途影响）。

## 7. 技术路线（已定稿：自研轻量播放引擎）

> **决策（2026-09-11）：弃用 tldraw SDK，不走第三方画布引擎。** 原因：
> 1. **License 硬伤**：tldraw SDK v5 为 source-available 专有许可，明确禁止生产环境使用，需商业授权；水印强制常驻；且会把使用数据回传给 tldraw（课堂用户数据经第三方，隐私不可接受）。
> 2. **场景错配**：tldraw 面向可编辑协作画布，我们的课堂是只读播放器——它的核心能力（工具系统、协作、选择编辑）全都用不上。
> 3. **成本**：React 全家桶 ~1MB+ vs 自研 ~15KB（rAF + viewBox 数学）；移动端与 SSR 负担差距悬殊。

**自研路线的工程起点就是本仓库外已验证的概念原型** `E:\agent3333\tldraw-explore\camera-board-demo.html`（纯 SVG + rAF，已完整验证 5 种运镜 + 9 种表演形式全流程），沉淀为 `lib\board-engine.ts`：

```
board-engine 模块划分
├── 相机模型    viewBox(x,y,w,h) + fitBounds/clamp + EASINGS（easeInOutCubic 等 5 条）
├── 节拍调度器  BEATS[]：每拍 {语音字幕, 相机动作, 板书动作[], 时长}，对接 TTS 时间轴
├── 表演原语    9 种（§4 表格）：落笔描线/弹出/圈重点/节点点亮/数据生长/路径运动/闭环旋转/面积填充/撒花
└── 角色层      角色锚点投影 + 蹦跳（挤压拉伸）+ 庆祝
```

节拍结构与引擎解耦：导演层（LLM 标注 `{形式, 目标元素, 参数覆盖}`）只产出 BEATS 数据，未来换渲染后端（如 Canvas2D）不需重写管线。

### 7.1 与现有管线的接线（最小改动）

```
讲稿 beat ─→ splitSpeechLines 切句 ─→ planItemLines 一句一动作（已有）
                                    ↓
                          【新增】导演层：LLM 按第 4 节选型三问，
                          为每句标注 {形式, 目标元素, 参数覆盖}
                                    ↓
                          board-engine 节拍调度器 → 相机 + 表演原语 + 角色动作
                                    ↓
                          TTS 时间轴对齐（时间接近原则）
```

## 8. 验收清单（每节课动画过一遍）

- [ ] 开场有全景地图，终拍有结课巡游
- [ ] 每句话有且只有一个主视觉事件，且与语音同步
- [ ] 同屏信息组块 ≤ 5；超出靠运镜解决而非缩字
- [ ] 全片运镜 ≤ 每 10 秒 1 次；相邻运镜隔完整节拍
- [ ] 无装饰性弹跳；庆祝时刻外无过冲
- [ ] 每拍留白 ≥ 300ms；最长节拍保障阅读时间（字数×180ms+800ms）
- [ ] 圈重点/点亮/路径运动的落点 = 该句话的核心结论
- [ ] 同一表演形式不连用 ≥ 3 次
- [ ] 角色不遮挡落笔区，动作都是次动作
- [ ] `prefers-reduced-motion` 下退化为线性跟滚 + 硬切
- [ ] 暂停时画面为完整板书状态
