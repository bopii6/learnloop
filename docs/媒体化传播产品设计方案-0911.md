# 媒体化传播产品设计方案

日期：2026-09-11
定位前提：Superlearn 的客群是「要交付作品的自学者」，传播策略必须服务于「看得见的学习体验 → 立刻扫码上手 → 付费」这条链路。

---

## 〇、总纲：三句话战略

1. **产品即内容**：白板课堂本身就是最好的宣传物料，不需要另外"制作"宣传内容。
2. **教室即直播间**：给课堂加一层「放映模式」，OBS 抓屏即开播，主播零讲解。
3. **回放即落地页**：每一个分享出去的回放链接，都是一篇会说话的落地页，看完就能转化。

现状判断（2026-09-11 摸底结论）：**生产端已完整，分发端全空白。**

| 环节 | 现状 | 缺口 |
|---|---|---|
| 物料生产 | 知识海报×2（board-poster.ts）、60s竖屏视频（VerticalClipModal.tsx）、公开回放页（/replay/[id]） | 视频缺片尾转化卡；缺多规格 |
| 分享预览 | 仅 layout.tsx:4-7 有 title+description | 全站无 OG 卡，微信/抖音分享出去是裸链接 |
| 转化承接 | 回放页公开可看（GET /api/replay 无 auth） | 回放页没有任何 CTA，游客看完就走 |
| 裂变机制 | 无 invite/referral 代码 | 邀请得积分、分享解锁均未做 |
| 直播场景 | 无任何适配 | 无放映模式、无 OBS 源、无实时二维码 |
| 商业化 | 兑换码单通道（/admin 造码）、四档定价已在 admin 页 | 无在线支付；兑换码未与直播/裂变玩法打通 |

---

## 一、P0：直播间放映包（用户点名的核心场景）

目标：**开播前 5 分钟准备完毕，直播全程零讲解，AI 讲师自己上课，观众扫码即学。**

### 1.1 放映模式（/learn?stage=1）

课堂页加一个 URL 参数进入放映模式，也可在顶栏加一个「放映」按钮：

- 隐藏一切 chrome：侧栏、顶栏、进度条、字幕条之外的全部控件淡出；鼠标静止 2 秒后自动隐藏光标。
- 画面规格对齐直播：内容区锁定 16:9 安全框，字号整体 +1 档（直播观众多在小屏/低码率下看）。
- 快捷键（主播遥控器）：`空格` 暂停/继续 TTS，`←/→` 上一拍/下一拍，`R` 重讲当前一句，`N` 跳下一节。主播唯一的活就是按时按空格，全程不用说话。
- 自动连播：`?stage=1&autoplay=1` 时，一节课谢幕卡停留 10 秒后自动进入同课程下一节；课程播完循环回第一节。挂机开播，人来就看。

### 1.2 OBS 直出

- 放映模式下页面背景即暖阳纸色，无滚动、无弹层，OBS「浏览器源」直接填 `/learn/{courseId}/{lectureId}?stage=1&autoplay=1`，分辨率 1920×1080。
- 提供一个 `/watch/{courseId}` 连播路由（自动按大纲顺序连播全部白板课节），专门喂 OBS；这条链接同时就是「频道」概念的地基。

### 1.3 角标二维码（直播间转化的命脉）

放映模式右下角常驻一张暖阳色小卡：

- 内容 = 本节课回放链接的二维码 + 一句话「扫码，AI 私教给你也开一门」+ 品牌字标。
- 二维码链接带渠道参数 `?ref=live`，注册时计入渠道来源（见 4.1）。
- 实现：客户端 qrcode 库画进一个 DOM 角标即可，不进白板 canvas，不影响导出。

### 1.4 直播间专属兑换码（现有系统直接支撑）

- /admin 造码页支持「批量前缀造码」，如 `SL-LIVE9-XXXXX`。
- 直播口播模板：「今晚直播间输入这个码，送 30 积分，够你白嫖生成三门课。」——兑换码本来就是唯一充值通道，正好把它变成直播间的转化钩子，等在线支付上线后它继续当优惠券用。

### 1.5 开场/谢幕卡（直播观感的两块门面）

- 开场：进入放映模式先播 3 秒标题卡（课程名 + 讲师小人 + 「Superlearn 出品」），从纸面点阵中落字，符合动画规范「动画是导演手段」。
- 谢幕：每节课结束播 5 秒谢幕卡——本课金句 + 二维码 + 「下一节：XXX」。谢幕卡就是直播间的口播替身。

## 二、P0：分享闭环补漏（工程量最小、杠杆最大）

### 2.1 全站 OG 分享卡

- `app/layout.tsx` 补 `metadataBase`、`openGraph`、`twitter` card；`/course/[id]` 与 `/replay/[id]` 各加 `generateMetadata`，标题模板「{课名}｜AI 私教 3 分钟给你开一门」。
- 动态 OG 图：新增 `app/api/og/route.tsx`（satori/@vercel/og，Node runtime），输入课程名+首图要点，输出 1200×630 暖阳色卡片（复用 board-poster.ts 的色板常量：PAPER #fffcf4 / INK #43301f / ACCENT #e8590c）。
- 验收标准：微信里发 /replay 链接，出来的是带课程名和暖阳封面的卡片，不是裸链接。

### 2.2 回放页 = 落地页（转化三件套）

回放页现在是「公开但裸奔」，补三个元素：

1. **顶部通栏**（可关闭）：「这门课是 AI 用 3 分钟生成的 → 你也可以，免费生成我的课」（带 ref 参数跳首页生成器）。
2. **中途卡点**：播到 60% 时白板上方浮出一次「免费开同款」气泡（整场只出一次，符合沉静红线，不打断）。
3. **结尾 CTA**：谢幕卡之后接转化条：注册送 20 分 = 能免费生成 2 门课，把数字写出来。

### 2.3 分享动作降摩擦

- 海报/视频导出弹窗里加「复制链接」和 `navigator.share`（移动端直接唤起系统分享面板）。
- 回放页与课程页加悬浮「分享」按钮，一键复制带 ref 的链接 + 出一张带个人二维码的邀请海报（见 4.2）。

## 三、P1：内容媒体化——让一门课长出一整套媒体矩阵

### 3.1 竖屏视频升级（现有 VerticalClipModal 基础上）

现有 60s 视频已能直发抖音/小红书，补三处转化设计：

- **片尾 3 秒转化卡**：二维码 + 「AI 私教，3 分钟给你开一门同款课」+ ref 短链。没有片尾码的视频只涨赞不涨客。
- **多规格**：30s（信息流广告位）/ 60s（现有）/ 3min 深度版（B 站/视频号）。同一剧本素材，只改选卡数量与节奏。
- **片头品牌钉**：前 0.8 秒统一「Superlearn · 白板私教」动态字标，做成系列辨识度。

### 3.2 图文卡片组（小红书/公众号刚需）

新增导出「卡片组」：把一节课讲义自动拆成 6~9 张 3:4 竖版卡片（封面卡=课程名+讲师小人，正文卡=现有 exportScriptPoster 的片段卡改竖版，尾卡=二维码），打包 zip 下载。小红书图文笔记的产量天花板直接被打开——一次导出，一周的笔记素材。

### 3.3 频道与连播（媒体形态的地基）

- `/watch/{courseId}` 连播路由（见 1.2），同时也是普通用户的「挂机听课」模式——地铁上、睡前听，把它变成一台知识电台。
- 课程页加「连播/单节」开关；回放页自动记忆上次看到的位置（localStorage 即可）。

### 3.4 嵌入播放器（B 端传播口）

`/embed/{replayId}`：无 chrome、只保留白板+字幕的纯净 iframe 版回放，允许别人嵌进自己的博客/ Notion / 公众号文章，底部一条细品牌条 linking 回落地页。每一次嵌入都是一条分销渠道。上线前提是把 OG 和回放转化做扎实（P0），否则嵌出去也是白流。

## 四、P1：裂变与增长基建

### 4.1 渠道与邀请积分

- 所有分享出去的链接统一带 `?ref={userId短码}`；注册落地时记录来源用户。
- 双向奖励：被邀请人注册即得 +10 分（叠加基础 20 分），邀请人 +10 分，上不封顶但单日上限 50 分（防刷）。
- 成本核算（credits-commerce-plan 口径）：建课 ¥0.3，20+10 分的新客成本 ≈ ¥3~4，只要邀请转化率 >3% 就是划算的，远低于知识付费行业 100~300 元的获客成本。
- 记录靠一行 `referredBy` 字段 + admin 总览页加一列即可，不必先建统计系统。

### 4.2 邀请海报

在现有 exportScriptPoster 的画布管线上加一个变体：暖阳色 1080×1920，主文案「我用 AI 私教 3 天做出了 XX（结课作品名）」+ 学员成果 + 个人邀请二维码 + 「扫码送你 30 积分」。让每个学员的结课瞬间自动变成一张招生海报——**结课工坊的交付物（学员作品）本来就是最好的广告素材，现在只差一张能发的图。**

### 4.3 免费额度即营销

- 未登录游客：允许免费听每节课前 3 分钟（replay 已全免费，正课卡登录墙；改成前 3 分钟免登录，之后弹「注册继续听，送 20 分」）——让「扫码进来的直播观众」零门槛先上瘾。
- 「首听免费」的账要算清：首听 TTS 成本 ¥0.5/人，转化率按 10% 算，获客成本 ¥5，依然远优于行业。

## 五、P1：商业化收口——让流量变成钱

### 5.1 在线支付（当前最大商业缺口）

- 短期（1 周内可上）：接个人可用的聚合支付（虎皮椒/Xorpay 类，微信 H5 支付），admin 四档定价（¥9.9/10分、¥29.9/32分、¥49.9/55分、¥99/115分）直接挂购买按钮，支付成功自动到账。兑换码保留，降级为「线下收款 + 直播间赠码 + 售后补单」通道。
- 中期：办个体户开支付宝当面付，去掉聚合通道抽成；账本按 credits.ts 预告迁 D1。
- 定价页话术锚点：按「一杯奶茶换三天私教」而非按积分卖；首屏放「算一笔账」——人工私教 300 元/小时 vs 全课程 49.9 元。

### 5.2 直播转化专属 SKU

- 「直播间同款」礼包：直播当晚限时 ¥19.9/40 分（码：SL-LIVE 前缀兑换码即可实现，无需新代码）。
- 集市（/market）上架作者分成：上架课程被购买，作者分成 30%——UGC 飞轮的点火器，放在支付打通后的下一个迭代，先在集市页挂「即将开放创作分成」预约。

### 5.3 数据闭环

- 关键漏斗五步，每步一个埋点事件（现有 `ll:` 事件前缀管线够用）：分享曝光 → 回放开播 → 扫码/点击 CTA → 注册 → 首次生成。
- 北极星指标建议：**回放→注册转化率**（衡量「内容自己会说话」是否成立）和 **K 因子**（人均带来新注册）。

## 六、P2：沉静感与专业感打磨（长期气质）

「沉静」是直播间和回放观众对产品气质的体感，来自三件事：

1. **更少的打扰**：全局审视现有弹层（导出弹窗、积分不足提示、客服气泡），能合并的合并、能延后的延后；放映/回放模式下保证 10 分钟内零弹层。沿用动画规范的一致性原则——装饰动画一律不做，提醒一律不满屏。
2. **更好的声音**：TTS 音色固定为品牌音色（Cherry 已是默认，不再让用户选，减少决策）；可选极低音量的粉底噪声垫底（图书馆白噪音），提升「自习室」沉浸感；句间停顿统一 300~500ms（规范已有，检查回放页是否同样生效）。
3. **更完整的仪式**：开场标题卡（1.5）→ 章节卡（每个 plan item 切换时 1.5 秒章节字卡，成本极低但「课程感」翻倍）→ 谢幕卡 → 结课证书（结课工坊通过后自动生成一张可分享的结课海报，复用邀请海报管线，把「作品名+验收通过」印上去）。证书是自学者愿意晒的东西，晒的动作就是传播。

## 附：直播间标准脚本（上线 P0 后即可照做）

1. 开播：OBS 浏览器源填 `/watch/{今晚的课}?stage=1&autoplay=1`，画面出现开场标题卡。
2. 口播一句话（唯一需要说的话）：「我不讲课，AI 私教在讲，你们直接看。想自己开一门同款的，扫右下角码，注册送 20 分；今晚输兑换码 SL-LIVE9-XXXX 再送 30 分。」
3. 中途每 20 分钟，按一下 `N` 切下一节，AI 自己报幕。
4. 下播前把回放链接发到粉丝群——回放页顶栏就是转化入口，这条链接接着在你睡觉时继续招生。
