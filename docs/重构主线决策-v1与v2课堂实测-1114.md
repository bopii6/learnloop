# 重构主线决策：v1 / v2 白板课堂实测对比（2026-11-14）

实测方式：本地全新账号，真实生成一门课（「Python 数据分析入门：用 pandas 做一份销售数据报表」，4 轮澄清 → 蓝图 → 6 单元 21 课节，约 1.5 分钟），同一课节 `lec-1-1` 分别在 v1（`/learn/...`，Excalidraw）与 v2（`/classroom/...`，卡片流）各跑一遍，1280×800 视口。

## 关键事实

- **用户实际进的是 v1。** 课程大纲 `CourseOutlineView` 跳 `/learn/...`（v1）；v2 只能手敲 `/classroom/...` 进入。最新一次提交做的 v2 从未接进主路径。
- **生成链路质量在线**：澄清题贴合主题、蓝图每单元写明「为结课作品贡献什么」、设计理由可读。这部分不是重构重点。

## 对比

| 维度 | v1（Excalidraw 板书） | v2（卡片流） |
|---|---|---|
| 学员"做"的时刻 | 底部「没跟上 / 重听 / 略过」；打断提问 | **课中小测 → 即时判对错 + 讲解 → 成就徽章**；输入框可提问/作答 |
| 可读性 | 画布大、字小，内容挤在中间一条 | 大字号 Markdown、代码块、KaTeX 公式，打字机逐字落 |
| 富媒体 | 无 | AI 配图、自包含互动动画（iframe） |
| 播放控制 | 暂停、语速、聆听、全屏 | **无暂停、无语速、无进度**，只有缩放/翻页/语音 |
| 课前设置 | 有：交流方式、称呼、计费说明 | **无**，进来就开讲 |
| 计费 | 开讲扣 1 分（复习免费） | **不扣分**（`/api/board` 无计费）——商业化漏洞 |
| 失败处理 | 多轮修复后稳定 | 未配出图 key 时配图卡**永远卡在「配图中…」** |
| 断线恢复 / 回放 / 剪辑 | 有（WS 快照、回放页、竖版剪辑） | 无 |
| 无障碍 | 一般 | 多个按钮无 label |
| 代码 | `CourseSession.tsx` 2062 行 + `board-writer.ts` 1708 行，播放器/WS/UI 混写；依赖 Excalidraw（体积大） | 拆成 `components/board/*`、`lib/board/*`，`WhiteboardSession.tsx` 1017 行；无重依赖 |

## 决策

**以 v2 为唯一课堂。** 理由：北极星文档的实测结论是「整节课唯一爽的时刻是弹题」——v2 把作答、反馈、徽章做成了课堂的骨架，v1 只有求救按钮；v2 的排版与富媒体对"讲清楚"更有利；代码结构也更干净，能承载后续演进。

**但不能直接切。** v2 缺的恰好是 v1 打磨了十几轮的"成熟度"。顺序是：

1. v2 补齐 v1 的必要能力：课前设置 + 开讲计费、暂停/语速/没跟上/重听、断线续播、配图失败降级、按钮 label。
2. 课程大纲入口切到 v2，`/learn` 重定向到 `/classroom`。
3. 回放改基于 v2 的确定性脚本重做。
4. 以上验证通过后，删除 v1（`CourseSession`、`board-writer`、Excalidraw 依赖及其周边）。

**同时下线**（与主线无依赖，可先删）：漫画课堂、独立苏格拉底页、竖版剪辑。苏格拉底的"学员作答、老师接住原话"并入 v2 的 ask 环节。

## 顺带发现

- 蓝图页「✓ 没问题，继续生成课程细节」按钮在无障碍树里不可见（自动化点不到）——与 0908 审查报告 P2-1 同一问题，仍未解决。
- deepseek-flash 默认开思考模式，思考 token 计入 `max_tokens`；JSON 类调用需显式 `thinking: {type: "disabled"}`，否则会被截断。模型路由层要按任务设置。
