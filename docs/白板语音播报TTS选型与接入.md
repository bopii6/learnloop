# 白板语音播报 TTS 选型调研与接入说明（2026-09-08）

## 背景

白板/回放的语音播报原来用浏览器自带 `speechSynthesis`（Windows 系统音色，如慧慧/晓晓），
听感机械、播报腔重。本次调研了国内主流云端 TTS 的价格与效果，并接入其中
**性价比最高** 的一家；未配置时自动回退系统音色，功能不受影响。

## 选型结论（先说答案）

**接阿里云百炼 `qwen3-tts-flash`**：

- **最便宜**：0.8 元/万字符（官方口径：1 个汉字算 2 字符，即 ≈ **1.6 元/万汉字**）。
  开通百炼后每款 TTS 模型送 **1 万字符**（≈5 千汉字，约 1~2 节课）免费额度。
  一节 30 句、每句 150 字的课约 4500 汉字 → **约 0.72 元/节**，比豆包/MiniMax 便宜近一半。
- **效果足够好**：千问 3 代 TTS，中文自然度远超系统音色；同价还有
  `qwen3-tts-instruct-flash`，可用一句指令控制语气（如"用亲切的老师语气讲"）。
- **接入简单**：一个 HTTP 接口（`POST /api/v1/services/aigc/multimodal-generation/generation`），
  非流式直接返回音频 URL；百炼控制台创建 API Key 即可用。
- 项目已有多家"可选云服务 + 未配置自动降级"的先例（DeepSeek LLM、百度 ASR、R2 存储），
  本方案沿用同一模式。

**没选它们的原因**：讯飞普通合成效果最接近现在要摆脱的"机械感"；腾讯云大模型音色价格不占优、
接入也偏重；MiniMax 效果好但最贵；豆包 2.0 效果延迟都好，但单价比千问贵约 75%，
且资源包起售门槛更高。

**另一个零成本选项（没采用）**：微软 Edge 的"Online Natural"神经音色有免费 Web 接口
（edge-tts / msedge-tts 项目），音质不错、不要 key，但属于**非官方接口**，随时可能失效，
商用合规性差，不适合放在产品链路里——仅适合个人玩玩。

## 已实现的接入

```
浏览器 speak() ──优先──> POST /api/tts（服务端持 key）──> 阿里云百炼 qwen3-tts-flash
     │                        │ 501/失败
     └──────回退──────────────┴──> window.speechSynthesis 系统音色（原行为不变）
```

| 文件 | 作用 |
| --- | --- |
| `app/api/tts/route.ts` | 云端合成代理：持 key 调百炼，长句按标点切块并行合成，进程内缓存（同文重复播不重复计费）；未配置返回 501 |
| `lib/tts-client.ts` | 客户端帮助：501 后本会话不再请求、blob 缓存、按序分段播放器（可暂停/停止） |
| `components/CourseSession.tsx` | 白板课堂播报：云端优先 + 系统音色兜底；播放当前句时预取下一句，衔接不空等 |
| `components/ReplayPlayer.tsx` | 回放页同样接入 |
| `.env` / `.env.example` | `DASHSCOPE_API_KEY`（必填）、`TTS_VOICE`/`TTS_MODEL`（可选） |

细节：

- 语速：云端音频用 `playbackRate` 跟随课堂倍速；暂停/退出/切语音都能立即停音。
- 长句：>200 字符按句末标点切块并行合成，客户端按序播放。
- 计费控制：客户端与服务端双层缓存，重播/续播同一句不再请求。
- 默认音色 `Cherry`（芊悦，中文女声）；可在 `.env` 改 `TTS_VOICE`。

## 怎么启用

1. 打开 [阿里云百炼 API-Key 页面](https://bailian.console.aliyun.com/?tab=model#/api-key)，
   开通模型服务（会送每款 TTS 模型 1 万字符免费额度），创建 API Key。
2. 在 `hyperlearn/.env` 里取消注释并填上 `DASHSCOPE_API_KEY=sk-xxx`。
3. 重启 `npm run dev`，开一节白板课即可听到新音色；不填 key 则一切照旧（系统音色）。

## 后续可选

- 想要"老师语气"更浓：把 `.env` 的 `TTS_MODEL` 换成 `qwen3-tts-instruct-flash`（同价），
  并在 `app/api/tts/route.ts` 的 `input` 里加一行 `instructions`（如 "亲切自然的青年女教师，
  讲解有耐心，重点处放慢语速"，≤100 字符）。
- 想进一步压成本：把播报文本换成 cosyvoice-v3.5-flash（同价、音色更多，需改走 WebSocket），
  或等豆包 2.0 促销资源包。
